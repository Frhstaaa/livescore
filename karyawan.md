# 👥 DAFTAR KARYAWAN & SKILL GSTACK (ANTIGRAVITY)

> **Tentang Dokumen Ini:**  
> Dokumen ini berisi daftar seluruh **Skill / Karyawan Spesialis** dari suite **gstack** yang terpasang di Antigravity Anda. Anda dapat memanggil keahlian mereka kapan saja melalui *slash command* (contoh: `/review`, `/qa`, `/ship`) untuk membantu pengembangan aplikasi secara profesional.

## 📂 Planning, Ideation & Leadership

| Perintah (*Command*) | Peran / Spesialis (*Role*) | Deskripsi & Tanggung Jawab |
| :--- | :--- | :--- |
| `/office-hours` | **YC Partner / Product Strategist** | Brainstorming ide produk, validasi model bisnis, dan mengasah value proposition layaknya office hours di Y Combinator. |
| `/plan-ceo-review` | **Chief Executive Officer (CEO)** | Menilai rencana fitur dari kacamata bisnis, prioritas strategis, dan dampak terhadap user experience. |
| `/plan-eng-review` | **Engineering Manager (EM)** | Review arsitektur teknis, edge cases, skalabilitas, dan mitigasi risiko sebelum coding dimulai. |
| `/plan-design-review` | **Design Director** | Memeriksa konsistensi visual, interaksi UX, hirarki konten, dan design system pada rencana fitur. |
| `/plan-devex-review` | **Developer Experience Lead** | Audit kemudahan setup, arsitektur API, kejelasan dokumentasi, dan kenyamanan tim developer. |
| `/autoplan` | **Auto-Review Orchestrator** | Menjalankan pipeline review otomatis (CEO, Design, Eng, DX) secara berurutan dengan keputusan otomatis. |
| `/spec` | **Lead Product Manager (PM)** | Mengubah ide yang masih abstrak menjadi spesifikasi teknis (PRD/Spec) yang presisi dan siap eksekusi dalam 5 fase. |
| `/retro` | **Agile Coach / Scrum Master** | Memandu retrospektif mingguan untuk mengevaluasi apa yang berjalan lancar, kendala, dan rencana perbaikan sprint. |

## 📂 Code Quality, Review & Security

| Perintah (*Command*) | Peran / Spesialis (*Role*) | Deskripsi & Tanggung Jawab |
| :--- | :--- | :--- |
| `/review` | **Senior Staff Code Reviewer** | Audit pra-merge/pull request secara mendalam terhadap keamanan SQL, race conditions, bug logika, dan integritas arsitektur. |
| `/cso` | **Chief Security Officer (CSO)** | Audit keamanan sistem tingkat tinggi, celah autentikasi, otorisasi, kebocoran data rahasia, dan injection. |
| `/health` | **Tech Lead / Code Health Inspector** | Dashboard inspeksi kualitas kode, mendeteksi anti-pattern, dead code, technical debt, dan kompleksitas kode. |
| `/investigate` | **Root Cause Investigator / Debugger** | Investigasi bug dan error secara sistematis sampai ke akar masalahnya (bukan sekadar menambal gejala). |
| `/careful` | **Safety Guardrail Officer** | Memberikan proteksi dan konfirmasi ekstra saat menjalankan perintah terminal yang berpotensi destruktif. |
| `/guard` | **Security Boundary Guard** | Membatasi jangkauan edit file hanya pada direktori tertentu untuk mencegah kerusakan file di luar cakupan task. |
| `/freeze` | **Directory Freezer** | Membekukan izin edit file ke direktori tertentu selama sesi pengerjaan. |
| `/unfreeze` | **Directory Unfreezer** | Mencabut batasan direktori edit agar file di seluruh workspace bisa dimodifikasi kembali. |

- `/spec buatkan spesifikasi untuk fitur export PDF laporan pertandingan`
